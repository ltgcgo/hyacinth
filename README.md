# Hyacinth
💨 Build web projects with speed.

Documentation available at [kb.ltgc.cc](https://kb.ltgc.cc/hyacinth/).

## Key features
- No BS configurations, just write your code and build.
- Uses `esbuild` (**JS**, CSS), `tdewolff-minify` (**HTML**, JS) and `lightningcss` (**CSS**) under the hood with automatic fallbacks. Enjoy sub-second build speed on every single module.
- Runtime agnostic, no bias towards any single runtime.
- Directory structured, flatly mapped.
- Static page build support included and ready with precompression.
